# Publicly funded startups: what became of each one

**Question.** Basque public startup money is public, so its recipients should be traceable. For every startup that received it: is it alive, how many people does it employ, what does it earn, what is it worth?

Position behind this: public money must be a way to the *next* thing, and the next thing must be named and tracked. If nobody tracks it, that is itself the finding.

## Planned sources

- BDNS / Infosubvenciones (national grants database; regional administrations must report).
- BOPV beneficiary resolutions: Ekintzaile, Basque Fondo, BIND 4.0, Gauzatu, Hazitek (startup beneficiaries), Diputaciones' startup programmes, BEAZ.
- Public VC portfolios: GCR (Basque Fondo, Ekintzaile fund, BasketekVenture FCR, Hazten Scale-up FCR), Seed Capital Bizkaia.
- Outcomes: libreborme/BORME (status), company sites, press, El Referente, free snippets from einforma/axesor.

## Status

First pass in progress: map the sources, then a pilot cohort of ~80 companies funded 2015–2021, so outcomes are visible. Output will be `startups.csv`, `sources.md`, `method.md` in this folder.
